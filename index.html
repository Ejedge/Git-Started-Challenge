README.md · WORKSHOP BRIEF

Why Git Started?

Designed for NU Dasmariñas students taking their first confident step into modern software collaboration—turning intimidating terminal errors into safe, practical team workflows.

PR #2026 — feat/safe-inclusive-git-workshop APPROVED

The workshop introduces students to Git and GitHub from the ground up—covering repositories, meaningful commits, branching strategies, pull requests, and collaborative team workflows.

With practical guidance from experienced GitHub practitioners, participants won't just memorize commands—they'll understand why version control protects their work and fosters an inclusive engineering culture where beginners feel safe to experiment, review, and ship.

CODE OF CONDUCT · SAFE & INCLUSIVE

Safe & Inclusive Version Control

Learning Git can feel overwhelming the first time you hit a detached HEAD or a merge conflict. Our room is built so every student feels welcome.

01

No Gatekeeping, Ever

Whether it's your first time opening a terminal or you already push daily, questions are celebrated—there are no "basic" questions in this workshop.

02

Safe Experimentation

Git's superpower is safety. We teach students how commits, branches, and git revert let you try bold ideas without fear of breaking everything.

03

Kind Pull Request Reviews

Code reviews focus on shared learning, inclusive language (main branch conventions), and uplifting teammates across NU Dasmariñas.
